# spotify-suggestive-local


this project analyzes your Spotify Extended Streaming History using local tools and generates yearly insights, visual charts, summaries, recommendations, and playful roasts. It works fully offline using a local language model through Ollama. The script creates charts for overall listening patterns and detailed yearly breakdowns, then stores everything in a charts folder inside your history directory.

tools/libs used : matplotlib, pandas, glob, json, random, os, torch (optional), requests, Ollama, llama3 local model
